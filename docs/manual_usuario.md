## Introducción

AmazonIA 4.0 es una plataforma de monitoreo microclimático diseñada para las comunidades de la cuenca del río Caroní. Este manual te guiará paso a paso en el uso del sistema.

---

## Acceso al Dashboard

1. Abre tu navegador web (Chrome, Firefox, Edge).
2. Ingresa a: **http://localhost:8501**
3. Verás la pantalla principal con los indicadores actuales.

---

## Interpretación de Indicadores

| Indicador | Significado | Rango Normal |
| :--- | :--- | :--- |
| 🌡️ Temperatura | Calor del aire | 20-35 °C |
| 💧 Humedad | Vapor de agua en el aire | 60-95 % |
| 🌧️ Precipitación | Lluvia acumulada | 0-50 mm |
| 🔋 Batería | Estado de la estación | > 3.5 V |

---

## Interpretación de Alertas

| Alerta | Significado | Acción Recomendada |
| :--- | :--- | :--- |
| ⚠️ Lluvia intensa | Precipitación > 50 mm | Evitar zonas bajas |
| 🔥 Calor extremo | Temperatura > 40 °C | Hidratarse, evitar sol |
| 🔋 Batería baja | Voltaje < 3.2 V | Reportar al técnico |
| 💨 Viento fuerte | Viento > 80 km/h | Asegurar objetos |

## Preguntas Frecuentes

**¿Puedo usar el sistema sin Internet?**
Sí, el sistema está diseñado para operar offline. Los datos se almacenan localmente y se sincronizan cuando hay conexión.

**¿Los datos son públicos?**
No, los datos sensibles de las comunidades están protegidos mediante anonimización y control de acceso.
